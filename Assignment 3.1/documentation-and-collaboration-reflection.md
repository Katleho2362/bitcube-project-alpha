# Documentation and Collaboration Reflection

Before updating the README, the repository mainly assumed that contributors already understood the project structure and sprint artefacts. The original README provided only a short project description and did not explain how the documentation or collaboration workflow was organised.

The updated README improves onboarding by giving new contributors a clearer understanding of the project purpose, sprint documentation structure, contribution workflow, and repository organisation. It also explains how Pull Requests should be used when contributing changes.

Through this assignment, I learned that Pull Requests and Issues are not only technical tools but also communication tools used to explain changes, request reviews, report problems, and collaborate professionally with other developers. I also learned the importance of writing documentation that is easy for new contributors to understand without additional explanation.
